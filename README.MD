## 💻 Infromações
### Build
- A build está sendo relizada pelo App Center, por enquanto, somente a do Android está configurada.
- A build está altomática para qualquer alterações realizada na branch "master", logo essa branch só deve sofrer alterações quando for para gerar build.
- Basta subir o commit na branch "master" para build ser realizada. Para ter certeza ser inicou normalmente, acessa a conta do App Center para ver e verificar.
- Caso ocorra tudo certo na build, acesse a conta do AppCenter e baixe a versão ou aguardar o e-mail que vai chegar para os testadores inseridos.

### key
Caso precise das keytore de assinatura, ela está presente no reporitório, abaixo estão suas credencias.

```bash
MYAPP_UPLOAD_STORE_FILE=kuba-upload-key.keystore
MYAPP_UPLOAD_KEY_ALIAS=key-upload-kuba
MYAPP_UPLOAD_STORE_PASSWORD=kubabuild
MYAPP_UPLOAD_KEY_PASSWORD=kubabuild
```
